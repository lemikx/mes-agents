# mes-agents

Agents et skills Claude Code.

- `agents/expert-informatique.md` : expert informatique tous domaines (Opus).
- `agents/haiku-worker.md` : recherches de sites et recherches simples (Haiku).
- `agents/sonnet-worker.md` : extraction de code, croisement de sources, dédoublonnage, conversion (Sonnet).
- `skills/` : diagnostic-reseau, depannage-windows-mac, admin-linux, wordpress-hebergement, sauvegarde.
- `CLAUDE.md` : règles générales.

## Installation sur un ordinateur (Claude Code)

    /plugin marketplace add lemikx/mes-agents
    /plugin install mes-agents@mes-agents

Mise à jour : `/plugin marketplace update mes-agents`.

## Sur le téléphone
Ouvrir une session Claude Code sur ce dépôt : agents et skills sont chargés via `.claude/`.
